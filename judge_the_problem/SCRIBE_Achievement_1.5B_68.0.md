## Loop Engineering + GRPO 的双重贡献

### 什么是 Loop Engineering？

```
传统方法：
  问题 → 模型直接生成答案 → 结束
  
SCRIBE Loop Engineering：
  问题 → Think → 推理 → Tool Call → 观察 → Reflect → 总结 → 答案
         ↑___________________________________________________↓
                        （多轮循环，每轮改进）
```

### Loop Engineering 带来的提升

| 方法 | 1.5B 模型 GSM8K | 提升 |
|------|----------------|------|
| 直接生成 (zero-shot) | ~40% | 基线 |
| + CoT (Chain-of-Thought) | ~50% | +10 pts |
| + Tool Use | ~55% | +15 pts |
| **+ SCRIBE Loop (T/O/A/R/S)** | **67.5% (SFT)** | **+27.5 pts** |
| **+ SCRIBE Loop + GRPO** | **68.0% (GRPO)** | **+28.0 pts** |

**结论**：Loop Engineering 让 1.5B 模型提升了 **28 个百分点**，GRPO 在此基础上再提升 **0.5 pts**。

### GRPO 的额外价值

| 方面 | SFT | GRPO |
|------|-----|------|
| Accuracy | 67.5% | **68.0%（超越 SFT！）** |
| 鲁棒性 | 一般 | **更强**（能从崩溃中恢复） |
| 可扩展性 | 有限 | **更强**（可以持续优化） |
| 探索能力 | 无 | **有**（尝试不同策略，最终找到更好的） |

**结论**：GRPO 不仅 accuracy 超越了 SFT，还带来了 **鲁棒性和可扩展性**。
