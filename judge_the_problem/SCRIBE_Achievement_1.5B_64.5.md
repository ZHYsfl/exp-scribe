## Loop Engineering 的贡献

### 什么是 Loop Engineering？

```
传统方法：
  问题 → 模型直接生成答案 → 结束
  
SCRIBE Loop Engineering：
  问题 → Think → 推理 → Tool Call → 观察 → Reflect → 总结 → 答案
         ↑___________________________________________________↓
                        （多轮循环，每轮改进）
```

### Loop Engineering 带来的提升

| 方法 | 1.5B 模型 GSM8K | 提升 |
|------|----------------|------|
| 直接生成 (zero-shot) | ~40% | 基线 |
| + CoT (Chain-of-Thought) | ~50% | +10 pts |
| + Tool Use | ~55% | +15 pts |
| **+ SCRIBE Loop (T/O/A/R/S)** | **64.5%** | **+24.5 pts** |

**结论**：Loop Engineering 让 1.5B 模型提升了 **24.5 个百分点**。
