## 优化路径：从 68% → 70%+

### Phase 1：添加学习率调度（预期 +1-2 pts）

**当前问题**：
```
Iter 40-49: lr=5e-6 固定
  → 模型在"突破"前还在震荡
  → 最后 9 iter 才提升 3.5 pts
  → 如果有退火，可能 iter_35 就达到 68%
```

**优化后预期**：
```
Iter 30-40: lr=2e-6 退火 → 稳定优化
Iter 40-50: lr=1e-6 精细 → 深入优化区

预期：
  - 无崩溃（warmup 缓冲）
  - 无震荡（退火稳定）
  - iter_40 可能达到 68%，iter_50 达到 70%
```

### Phase 2：Reward 权重调整（预期 +1-2 pts）

**当前问题**：
```
w1=0.32 → 68% reward 与解题无关
→ 模型走弯路（iter 12 reward 峰值但 accuracy 下降）
```

**优化后**：
```
w1=0.55 → answer correctness 主导
w6=0, w11=0 → 关闭易被 hack 的指标

预期：
  - 模型直接优化"解题能力"
  - 减少弯路，更快收敛
  - 可能再提升 1-2 pts
```

### Phase 3：Group Size + KL 约束（预期 +0.5-1 pt）

**优化**：
```
group_size=8  → 更稳定的 baseline
β=0.1        → 更强的 KL 约束
```

**预期**：
- 减少噪声导致的错误更新
- 更稳定的收敛路径

### Phase 4：Metric 16（跨 Turn 重复惩罚）（预期 +0.5-1 pt）

**作用**：
```
防止模型在多个 turn 中重复提交相同答案
→ 强迫模型真正改进
→ 减少"躺平"行为
```
